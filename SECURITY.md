# Security Policy

## Supported versions

Only the latest code on `main` is supported. There are no released versions yet.

## Reporting a vulnerability

If you find a security vulnerability, please do not open a public GitHub issue.

You can report it either:
- Via GitHub's private vulnerability reporting (Security tab → "Report a vulnerability"), or
- By email to jonnymthdev@gmail.com

Please include steps to reproduce, the affected component, and the potential impact.

## Scope

This covers security vulnerabilities in the strict sense: authentication/authorization
bypass, data exposure between restaurant accounts, injection, JWT/token handling, and
similar issues.

Bugs related to incorrect or missing allergen data for a dish are not security
vulnerabilities and should be reported as a normal GitHub issue instead.

## Response time

Best-effort response — no guaranteed SLA, as this is a solo-maintained project.
